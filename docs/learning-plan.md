# 学習ロードマップ

方針の元: [archive/gtp-advice.txt](../archive/gtp-advice.txt)

「全体像を知ること」と「全コードを読むこと」は別物。小さく変更して学ぶ。

## ゴール

自分用のブラウザを、保守できる形で持つ。

- 使う機能だけを残す（不要な機能を削る）
- 残した機能の構造を説明できる
- 自分の機能を1つ追加できる
- 上流のセキュリティ更新に追従できる

機能の選別・削除計画は [features.md](features.md) に置く。

## 原則

1. 機能追加より先に、機能の棚卸しと削減
2. 1回の変更は小さく（Hide → Disable → Remove）
3. 変更したらビルドして目で確認
4. 1機能 = 1コミット、学びは `docs/notes/` に残す
5. 全コードは読まない。必要になった場所だけ
6. AI 機能と Google 連携は極力出さない（[features.md](features.md) の方針）

## ステージ

### Stage 0: 基盤（完了）

- ビルド・起動・git・ドキュメント・`scripts/dev.sh`
- NTP の CSS / HTML の練習（背景色・検索ボックスの幅・ラベル）

### Stage 1: 機能の棚卸し（次）

| # | タスク | 学ぶこと |
|---|---|---|
| 1-1 | ユーザーに見える機能をリスト化 | 機能と画面の対応 |
| 1-2 | 使う／使わない／迷うを分類 | 優先順位 |
| 1-3 | コードの場所と依存を調査 | ディレクトリ、`BUILD.gn` |
| 1-4 | `features.md` に削除計画を書く | リスク評価 |

到達目標: 機能とコードの対応が分かる。削除する順番が決まる。

### Stage 2: 削減の練習（NTP / WebUI）

| # | タスク | 学ぶこと |
|---|---|---|
| 2-1 | NTP の不要モジュールを UI から隠す | CSS / HTML / フラグ |
| 2-2 | 設定画面の関連項目を外す | WebUI、prefs |
| 2-3 | コードを削除し `BUILD.gn` を更新 | 依存関係、ビルド |

到達目標: Hide → Disable → Remove を1周する。

### Stage 3: ブラウザ UI の削減（Views）

| # | タスク | 学ぶこと |
|---|---|---|
| 3-1 | ツールバーの不要ボタンを外す | Views、commands |
| 3-2 | タブの不要機能を外す | Views、Browser |
| 3-3 | メニュー項目を整理する | commands |

到達目標: Views の構造が分かる。

### Stage 4: 設定・サービスの削減（prefs / services）

| # | タスク | 学ぶこと |
|---|---|---|
| 4-1 | GN args で無効化して影響を測る | GN、ビルド |
| 4-2 | コード削除（可能な範囲） | services、依存 |
| 4-3 | prefs を整理する | prefs |

到達目標: 設定とサービスの依存が分かる。

### Stage 5: 構成図と残った機能の理解

| # | タスク | 学ぶこと |
|---|---|---|
| 5-1 | 構成図（起動 → ウィンドウ → タブ → ツールバー → 表示 → 設定 → ビルド） | 全体像 |
| 5-2 | 残った機能のコードを読む | 逆引き |

到達目標: 改造したい場所に自分でたどり着ける。

### Stage 6: 自分の機能を追加

| # | タスク | 学ぶこと |
|---|---|---|
| 6-1 | NTP のラベルを設定で切り替える | UI → prefs → 表示 |
| 6-2 | ツールバーにボタンを追加 | Views、commands |
| 6-3 | 一気通貫の機能 | 全体 |

到達目標: UI から内部処理まで追える。

## マイルストーン

- M1: 機能台帳（全機能のリスト）
- M2: 削除計画（Keep / Remove / Defer）
- M3: 最初の機能削除（NTP）
- M4: ブラウザ UI の削減
- M5: 構成図
- M6: 自分の機能

## 読むべき場所（入口）

| 対象 | 場所 | 役割 |
|---|---|---|
| ブラウザウィンドウ | `chrome/browser/ui/views/frame/` | ウィンドウ・ツールバー周辺 |
| タブ | `chrome/browser/ui/views/tabs/` | タブの表示・操作 |
| 新しいタブ | `chrome/browser/resources/new_tab_page/` | NTP の画面 |
| 設定画面 | `chrome/browser/resources/settings/` | 設定 UI |
| 設定の保存 | `chrome/browser/prefs/` | 設定の登録・保存 |
| アイコン等 | `chrome/app/theme/` | 画像リソース |

## 運用: 上流更新

- 月1回、またはセキュリティ修正時に [upstream.md](upstream.md) の手順で取り込む
- コンフリクトは自分で解消する
- 変更一覧は [customizations.md](customizations.md) に残す

## 進め方

1. タスクを `todo.txt` の「進行中」に1つだけ書く
2. コードはエージェントが提案し、ユーザーが適用する
3. `./scripts/dev.sh` でビルド＋起動し、目で確認
4. 動いたらコミット、学びを `docs/notes/` に残す
5. 詰まったら「どの層か」（WebUI / Views / prefs / services / ビルド）を切り分ける
6. 削除は Hide → Disable → Remove の順で、1機能ずつ
